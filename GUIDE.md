# Getting started

Download [Release](../../releases/latest) or [Beta](../../releases/tag/v1.0.1-test.67) with X-Plane closed.

For a manual install, follow INSTALL-ONE-FOLDER.txt inside the ZIP. Copy its XPFSR24 folder into your X-Plane 12 Resources/plugins folder and run IntegrationSetup.exe from that installed folder. After starting X-Plane, open Plugins > Aerolux Ultimate Pro: Aviators Edition > Open settings.

Release includes XPFSR24/AeroluxManager.exe. Open it with X-Plane closed to install, update or switch downloads through Aerolux Manager.

Neural Lighting for Stock Clouds starts Off. Neural Rendering uses a compatible model imported locally. For HDR and frame generation, follow the compatibility guidance shown in the panel.

## Ray tracing in Beta

Open World, then Ray tracing. Enable the effects you want and restart X-Plane. Aerolux traces a simplified terrain and aircraft scene. The panel shows which denoisers are running and when Keep my FPS pauses an effect.

NRD filters, RTXDI GI reuse and SHARC caching run through Vulkan. AMD Ray Regeneration needs supported AMD hardware. NVIDIA Ray Reconstruction needs an NVIDIA RTX GPU and DLSS selected. NVIDIA RTX flight verification remains a community hardware check.

Photo mode includes Path traced accumulation. Keep the camera still while it accumulates.

If you need help, [ask in Discussions](../../discussions). If something goes wrong, use [Report a problem](../../issues/new?template=report.yml). If the mod will not start, use the [Startup check form](../../issues/new?template=startup.yml).

Reports are public. Open your report file and remove anything you do not want to share before attaching it.
