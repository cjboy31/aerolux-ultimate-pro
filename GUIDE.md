# Getting started

Download the [Windows release](../../releases/tag/v1.0.0). To use Aerolux Manager, extract its ZIP to a writable folder and run XPlaneFSR24.exe with X-Plane closed. Select your simulator copy and open the Aerolux Ultimate Pro page to install or update.

For a manual install, follow INSTALL-ONE-FOLDER.txt in the plugin ZIP. After starting X-Plane, open Plugins > Aerolux Ultimate Pro: Aviators Edition > Open settings.

Neural Lighting for Stock Clouds starts Off. For HDR, enable Windows HDR and turn Aerolux's Vulkan frame generation Off, then restart X-Plane.

If you need help, [ask in Discussions](../../discussions). If something goes wrong, use [Report a problem](../../issues/new?template=report.yml). If the mod will not start, use the [Startup check form](../../issues/new?template=startup.yml).

Reports are public. Open your report file and remove anything you do not want to share before attaching it.
