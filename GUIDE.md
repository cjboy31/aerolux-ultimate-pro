# Getting started

Aerolux Ultimate Pro: Aviators Edition is being prepared for release. When a download is available, the release page will include the installation steps for that build.

If you need help, [ask in Discussions](../../discussions). If something goes wrong, use [Report a problem](../../issues/new?template=report.yml). If the mod will not start, use the [Startup check form](../../issues/new?template=startup.yml).

Reports are public. Open your report file and remove anything you do not want to share before attaching it.
